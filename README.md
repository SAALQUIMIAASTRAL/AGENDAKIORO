# KIORO · Agenda Digital Astral

Primera vista para pruebas (v0.1). Abrir index.html en un navegador o servir como sitio estático.

Incluye cuaderno por día, navegación mes/semana/día, tareas con stickers, notas, finanzas en MXN, metas de ahorro mensuales, portada de mes, perfil local con foto y resumen de privacidad de la prueba.

Datos astrológicos: cielo de enero de 2027 y retrogradaciones de 2027. Otros meses pendientes de completar. Los mensajes y la guía de belleza son interpretaciones generales, sin personalización natal.

Datos guardados solo en el navegador. No hay cuentas registradas ni sincronización con Supabase todavía. Horaria, Feng Shui, clima de mercados, Google Calendar y Outlook están señalados como pendientes; no se realizan consultas externas. No hay cobros ni suscripciones implementados. No se incluyen claves privadas.

Para la prueba visual: navegar fechas, escribir notas, añadir tareas y marcarlas, registrar ingresos/gastos/ahorro, guardar una meta y recargar para verificar la persistencia en el mismo navegador. Los datos locales pueden borrarse desde Mi cuenta.

Revisión visual en móvil y pruebas completas del nuevo código pendientes. Esta vista no constituye un despliegue de producción ni una edición lista para imprenta.
